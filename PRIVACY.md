# Privacy Policy

Effective September 29, 2026

Site Command Palette does not transmit, sell, or share personal data. It does
not use analytics, advertising, or remote code.

The extension handles and stores the following data locally in Chrome:

- commands you create, including their names, URLs, and site scopes;
- appearance and keyboard-shortcut preferences; and
- automatic-backup settings.

Site Command Palette runs on HTTP and HTTPS pages so it can display the command
palette and use the current hostname to show relevant commands. When you choose
to add a command, it also uses the current page's title and URL to prefill the
form. This page information is not transmitted.

If you enable automatic backups, the extension writes a JSON backup containing
your commands and settings to a folder you choose on your computer. The folder
permission and backup state remain in your browser. The extension does not
upload these backups.

You can delete commands within the extension, clear the extension's data through
Chrome, or uninstall the extension. Backup files already written to your chosen
folder must be deleted separately.

Questions or privacy concerns can be reported through the
[project issue tracker](https://github.com/DannyBen/site-command-palette/issues).
