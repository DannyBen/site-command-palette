# Chrome Web Store Texts

## Summary

A fast, contextual command palette for saving and recalling pages across the sites you use.

## Description

Site Command Palette gives every website a fast, keyboard-first command palette for the pages you use most. Save a page once, then recall it in a few keystrokes without hunting through bookmarks or menus.

Your data stays yours. Commands and preferences are stored locally in your browser. If you enable backups, they are written only to a folder you choose on your computer. There are no accounts, analytics, ads, or cloud services, and nothing is sent to us. Site Command Palette is open source, so its behavior can be inspected.

KEY FEATURES

• Contextual commands — see links for the current site by default, or switch to all your saved commands with a single key.

• Fast fuzzy search — find a command by typing a few letters, even when they are spread across its site and page names.

• Keyboard-first navigation — open the palette, search, select, and navigate without reaching for the mouse.

• Flexible scope — save commands for one site, make them available everywhere, or use a custom site pattern.

• Quick actions — add the current page, edit saved commands, open links in a new tab, and change the current site's theme directly from the palette.

• Your choice of appearance — use Light, Dark, or System theme globally, with optional overrides for individual sites.

• Configurable shortcuts — customize the keys used to open the palette and manage commands.

• Site controls — completely disable the extension on sites where you do not want it to run.

• Optional local backups — keep versioned JSON backups in a folder you choose on your computer.

HOW TO USE IT

1. Press ` (backtick) to open the palette. Alt+` also works when you are typing in a page field.
2. Press Alt+A to save the current page.
3. Start typing to find a command, then press Enter to open it.
4. Press Tab to switch between commands for the current site and all commands.
5. Press Ctrl+Enter to open the selected command in a new tab.
